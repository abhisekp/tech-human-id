    04 / BEFORE YOU GO

    A few good questions.

    How many combinations are there?+

    The default word lists contain 75 adjectives, 150 tech nouns, and 96 verbs: 1,080,000 word combinations. Each extra adjective multiplies the pool by 75; an adverb multiplies it by 59. The playground calculates the pool for your settings.

    Are the IDs unique?+

    Each call makes an independent random selection, so repeats are possible. If an ID must be unique, check it against existing records and retry on a collision. Different word combinations can also produce the same string when separators are omitted.

    Where should I use them?+

    Readable labels for datasets, dev environments, demo projects, logs, or shared sessions. The generator uses Math.random(), so use a cryptographically secure generator for passwords, authentication tokens, and other secrets.

    Can I contribute a word?+

    Absolutely. The word lists live in the data directory. Keep words short, family friendly, and relevant to tech, then open a pull request on GitHub.
